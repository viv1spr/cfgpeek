Autoexec в CS2: как создать, куда положить и почему не работает

Autoexec — это файл с командами, который CS2 выполняет при запуске. Показываем, где его создать, как подключить и что проверить, если настройки не применяются.

Что такое autoexec

Это обычный текстовый файл с расширением .cfg. В нём построчно записаны консольные команды: сенса, viewmodel, бинды, прицел. Игра выполняет их по очереди, как будто вы ввели их в консоль сами.

Готовый конфиг любого игрока можно взять на его странице кнопкой «Скопировать конфиг», например у donk или ZywOo.

Как проверить, что он работает

Запустите игру, откройте консоль клавишей ~ и введите команду ниже. Если файл найден, в консоли появится строка из последней команды echo.

Console
exec autoexec

05Файл найден и выполнен

Console
] exec autoexec
autoexec loaded
] _

Почему autoexec не работает

06Ошибка: файл не найден

Console
] exec autoexec
exec: couldn't exec 'cfg/autoexec.cfg', unable to read file
] _
  • Файл называется autoexec.cfg.txt. Включите в Проводнике Вид → Расширения имён файлов и переименуйте.
  • Файл лежит не в той папке. Нужна именно game\csgo\cfg внутри папки игры, а не csgo\cfg в корне.
  • В параметре запуска опечатка. Должно быть +exec autoexec.cfg, с плюсом в начале.
  • Команда из CS:GO, которой нет в CS2, например cl_bob. Консоль покажет Unknown command, остальные строки всё равно выполнятся.
  • Настройки сбрасываются после перезапуска. Добавьте в конец файла host_writeconfig, чтобы игра записала значения.

Файл можно назвать как угодно, например donk.cfg, и запускать командой exec donk. Только не ставьте лишних точек в имени: autoexec.donk.cfg игра может не найти.

Частые вопросы

Где лежит autoexec в CS2?

В папке игры: Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg.

Нужен ли +exec autoexec в параметрах запуска?

Игра часто подхватывает autoexec сама, но с параметром +exec autoexec.cfg он гарантированно выполнится при каждом запуске.

Почему не применяется autoexec?

Чаще всего файл называется autoexec.cfg.txt или лежит не в game\csgo\cfg. Проверьте командой exec autoexec в консоли.
