Comment importer le viseur d'un pro dans CS2

Copiez un code de viseur depuis la page de n'importe quel joueur et collez-le dans les réglages de CS2. Le pas-à-pas, et quoi faire si le code est refusé.

Vous pouvez récupérer n'importe quel viseur de CfgPeek de deux façons : avec un code qui commence par CS ou avec des commandes console.

Avec un code

  1. Ouvrez la page du joueur et cliquez sur « Copier ».
  2. Dans CS2, allez dans Réglages → Jeu → Viseur.
  3. Cliquez sur « Partager ou importer » et collez le code.
  4. Confirmez l'import et testez le viseur sur une carte.

Avec la console

Copiez les commandes console et collez-les ligne par ligne dans la console, ou toutes d'un coup dans autoexec.cfg.
