Quel est le code de viseur de susp sur CS2 ?

Code de viseur de susp : CSpV882p4P6Bv5skhyzLArWudJfYaqHxSx39mUyPLvxPYE. Copiez-le et collez-le dans CS2 : Réglages → Viseur → Partager ou importer.

Quelle sensibilité utilise susp ?

0.55 à 800 DPI (eDPI 440), sensi au zoom 0.87, 94.5 cm/360°.

Dans quelle résolution joue susp ?

1280×960, 4:3 black bars.

Comment récupérer la config de susp ?

Cliquez sur « Copier la config » en haut de la page et collez le texte dans autoexec.cfg, dans le dossier cfg du jeu. Elle contient la sensibilité, le viewmodel, le HUD, le radar, le code du viseur et les options de lancement.
