Aperçu des réglages

Viseur de Evelone sur CS2 : croix, couleur cyan, longueur 2, épaisseur 2, écart 1. 36 des 92 pros de notre base utilisent la même couleur. Evelone joue en sensi 1.8 à 400 DPI (720 eDPI), en dessous de la médiane des pros (800 eDPI). Résolution : 1280×960 4:3 stretched, utilisée par 21 pros de notre base, dont Mokrivskyi.

Quel est le code de viseur de Evelone sur CS2 ?

Pas encore de code au nouveau format. Réglages : longueur 2, épaisseur 2, écart 1, couleur RVB 50, 250, 250.

Quelle sensibilité utilise Evelone ?

1.8 à 400 DPI (eDPI 720), sensi au zoom 1, 57.7 cm/360°.

Dans quelle résolution joue Evelone ?

1280×960, 4:3 stretched.

Comment récupérer la config de Evelone ?

Cliquez sur « Copier la config » en haut de la page et collez le texte dans autoexec.cfg, dans le dossier cfg du jeu. Elle contient la sensibilité, le viewmodel, le HUD, le radar, le code du viseur et les options de lancement.
