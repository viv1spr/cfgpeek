Convertisseur de viseur

Collez un ancien code CSGO-xxxxx-xxxxx-… et obtenez un code au nouveau format de CS2, introduit avec la mise à jour des viseurs de septembre 2026.

Par exemple, essayez l'ancien code de s1mple : CSGO-iCxok-KTVNX-shCzf-Evoek-weaAB

Le nouveau code et l'aperçu s'afficheront ici.

À propos du nouveau viseur

Pourquoi mon ancien code de viseur CSGO- ne marche plus ?

En septembre 2026, Valve est passé à un viseur en pixels et, le 30 septembre, a changé le format des codes : les nouveaux commencent par CS et n'ont pas de tirets, et le jeu refuse les anciens CSGO-.

Comment retrouver mon ancien viseur après la mise à jour de CS2 ?

Collez votre ancien code CSGO- dans le convertisseur ci-dessus, choisissez la résolution dans laquelle vous jouiez, copiez le nouveau code et importez-le : Réglages → Viseur → Partager ou importer.

Quelle est la précision de la conversion ?

La longueur et l'épaisseur sont recalculées avec l'ancienne formule du jeu (1/480 de la hauteur d'écran) et l'écart avec l'ancienne formule en pixels. Le résultat est en général identique ou à 1 pixel près ; si votre viseur était dynamique, choisissez le style dynamique à la main.
