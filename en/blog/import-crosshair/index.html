How to import a pro crosshair in CS2

Copy a crosshair code from any player page and paste it in the CS2 settings. A step-by-step guide with pictures, plus what to do if the code is rejected.

You can take any crosshair on CfgPeek in two ways: with a code that starts with CS, or with console commands. The code is faster; commands are handy if you keep your settings in autoexec.cfg.

With a code

With the console

Open the console (the ~ key, if it's enabled in the settings) and paste the commands one line at a time. This is a crosshair as commands:

cl_crosshairstyle 4
cl_crosshair_length 7
cl_crosshair_thickness 2
cl_crosshair_gap 4
cl_crosshaircolor 5
cl_crosshaircolor_r 0
cl_crosshaircolor_g 255
cl_crosshaircolor_b 238
cl_crosshairdot 0
cl_crosshair_drawoutline 1

Save these lines in autoexec.cfg in the game's cfg folder so the crosshair sticks.

If the code is rejected

  • The code starts with CSGO-: that's the old format and CS2 no longer accepts it. Convert it in the crosshair converter.
  • The code was cut off: a new code is CS plus 44 characters with no spaces.
  • A space got pasted at the start or the end: delete it.

FAQ

How do I paste a crosshair code in CS2?

Settings → Game → Crosshair → "Share or Import", paste the code and click "Import".

Why doesn't CS2 accept my crosshair code?

It's probably an old CSGO- code or it was copied only partly. You can convert an old code in the CfgPeek converter.
