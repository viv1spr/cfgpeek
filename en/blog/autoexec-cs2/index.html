CS2 autoexec: how to create it, where to put it and why it doesn't work

An autoexec is a file of commands CS2 runs on launch. Here's where to create it, how to hook it up and what to check when your settings don't apply.

What an autoexec is

It's a plain text file with a .cfg extension. Each line is a console command: sens, viewmodel, binds, crosshair. The game runs them in order, as if you typed them into the console yourself.

You can grab any player's ready config with the “Copy config” button on their page, for example donk or ZywOo.

How to check that it works

Launch the game, open the console with ~ and type the command below. If the file is found, the console prints the line from the last echo command.

Why your autoexec doesn't work

06Error: file not found

Console
] exec autoexec
exec: couldn't exec 'cfg/autoexec.cfg', unable to read file
] _
  • The file is called autoexec.cfg.txt. In File Explorer turn on View → File name extensions and rename it.
  • The file is in the wrong folder. It has to be game\csgo\cfg inside the game folder, not csgo\cfg at the root.
  • There's a typo in the launch option. It should be +exec autoexec.cfg, with the plus sign.
  • A CS:GO command that doesn't exist in CS2, such as cl_bob. The console shows Unknown command, the other lines still run.
  • Settings reset after a restart. Add host_writeconfig at the end of the file so the game saves the values.

You can name the file anything, such as donk.cfg, and run it with exec donk. Just avoid extra dots in the name: the game may not find autoexec.donk.cfg.

FAQ

Where is the autoexec in CS2?

In the game folder: Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg.

Do I need +exec autoexec in launch options?

The game often picks up the autoexec by itself, but with +exec autoexec.cfg it is guaranteed to run on every launch.

Why isn't my autoexec working?

Most often the file is called autoexec.cfg.txt or isn't in game\csgo\cfg. Check with exec autoexec in the console.
