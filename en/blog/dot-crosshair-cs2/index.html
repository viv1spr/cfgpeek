Dot crosshair in CS2: how to make one and which pros play a tiny crosshair

A dot crosshair barely covers the enemy model and suits precise shooting. Here's how to set one up, plus the smallest pro crosshairs.

How to make a dot crosshair

  1. Open Settings → Crosshair.
  2. Turn on the center dot.
  3. Set the line length to zero so only the center is left.
  4. Pick the thickness: it sets the size of the dot. 2–3 pixels is usually enough to see it.
  5. Turn on the outline if the dot gets lost on light backgrounds.

You don't have to build it by hand: if a pro uses a dot, their code imports in a couple of seconds.

Pros and cons of a dot

  • Pro: it doesn't cover the enemy's head at long range.
  • Pro: handy for taps and first bullets.
  • Con: harder to see in smoke, on light walls and during fast movement.
  • Con: it doesn't show spread and takes longer to get used to.

FAQ

How do I make a dot crosshair in CS2?

In Settings → Crosshair turn on the dot, set line length to zero and pick the thickness, which sets the dot size.

Do pros use a dot crosshair?

Rarely: 2 of 92 players in our database use a dot, the rest play a small cross.
